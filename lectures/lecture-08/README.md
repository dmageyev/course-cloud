# Лекція 8: Безпека хмарних систем

## Огляд

Ця лекція присвячена аспектам безпеки хмарних інформаційних систем.

## Теми

1. Моделі відповідальності за безпеку
2. Ідентифікація та аутентифікація
3. Контроль доступу: RBAC, ABAC
4. Шифрування даних
5. Комплаєнс та сертифікація
6. Приклади AWS: IAM, KMS, CloudTrail, Security Groups

## Тривалість

90 хвилин

## Матеріали

- `notes.md` - Детальний конспект лекції
- `slides.md` - Презентаційні слайди
- `references.md` - Список літератури та ресурсів

## Очікувані результати

Після вивчення цієї лекції студенти зможуть:
- Пояснювати модель спільної відповідальності
- Проектувати політики контролю доступу
- Розуміти принципи криптографічного захисту
- Аналізувати вимоги комплаєнсу
