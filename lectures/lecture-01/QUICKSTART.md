# 🚀 Швидкий старт - Лекція 1

## Для викладача: Презентація готова!

### Варіант 1: HTML-презентація (НАЙПРОСТІШИЙ) ⭐

**Просто відкрийте файл:**
```bash
cd lectures/lecture-01
open presentation.html
```

Або подвійний клік на файлі `presentation.html` в файловому менеджері.

**Готово!** Презентація відкриється в браузері з професійним дизайном.

### Навігація в HTML-презентації

- **Стрілки ← →** - перехід між слайдами
- **Пробіл** - наступний слайд
- **Кнопки на екрані** - "Назад" і "Вперед"
- **Home** - перший слайд
- **End** - останній слайд

### Що включено?

✅ **50 слайдів** з повним матеріалом лекції  
✅ **Прогрес-бар** показує прогрес презентації  
✅ **Лічильник** показує номер поточного слайда  
✅ **Анімації** для плавних переходів  
✅ **Responsive** - працює на будь-яких екранах  
✅ **Мобільна підтримка** - свайпи працюють

## Варіант 2: Markdown слайди

```bash

marp slides.md --pdf
```
