# Інструкція з використання матеріалів Лекції 1

## Для викладачів

### Підготовка до лекції

1. **Ознайомтесь з матеріалами**:
   ```bash
   cd lectures/lecture-01
   cat README.md        # Огляд лекції
   less notes.md        # Детальний конспект
   ```

2. **Підготуйте презентацію**:
   
   **Варіант А: HTML-презентація (РЕКОМЕНДОВАНО!) 🌐**
   ```bash
   # Просто відкрийте готовий HTML файл
   cd lectures/lecture-01
   open presentation.html        # macOS
   xdg-open presentation.html    # Linux
   start presentation.html       # Windows
   
   # Або через веб-сервер для надійності
   python3 -m http.server 8000
   # Відкрийте http://localhost:8000/presentation.html
   ```
   
   **Переваги HTML-презентації**:
   - ✅ Не потрібні додаткові інструменти
   - ✅ Працює в будь-якому браузері
   - ✅ Красивий дизайн з анімаціями
   - ✅ Клавіатурна навігація
   - ✅ Підтримка мобільних пристроїв
   - ✅ Прогрес-бар та лічильник слайдів
   
   **Варіант Б: Конвертація в PDF/PPTX з Marp**
   ```bash
   # Встановіть Marp CLI
   npm install -g @marp-team/marp-cli
   
   # Конвертуйте в PDF
   marp slides.md --pdf -o lecture-01-slides.pdf
   
   # Або в PowerPoint
   marp slides.md --pptx -o lecture-01-slides.pptx
   ```
   
   **Варіант В: Онлайн редактор**
   - Відкрийте https://marp.app/
   - Завантажте slides.md
   - Експортуйте в потрібний формат
   
   **Варіант Г: reveal.js презентація**
   ```bash
   # Використайте reveal-md
   npm install -g reveal-md
   reveal-md slides.md
   ```

3. **Підготуйте live demo** (опціонально):
   - Створіть тестовий AWS акаунт
   - Підготуйте сценарій демонстрації
   - Перевірте інтернет-з'єднання

### Домашнє завдання

**Крок 1: AWS акаунт**
```bash
# 1. Зареєструйтесь на aws.amazon.com
# 2. Налаштуйте MFA
# 3. Створіть billing alert
```

**Крок 2: Перша EC2 instance**
```bash
# Через AWS Console:
1. EC2 → Launch Instance
2. Виберіть Amazon Linux 2
3. t2.micro (Free Tier)
4. Налаштуйте security group
5. Створіть key pair
6. Launch!

# Підключіться:
ssh -i your-key.pem ec2-user@<public-ip>

# ВАЖЛИВО: Зупиніть після експериментів!
```

**Крок 3: AWS CLI**
```bash
# Встановлення (Linux/Mac)
curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o "awscliv2.zip"
unzip awscliv2.zip
sudo ./aws/install

# Налаштування
aws configure

# Тест
aws ec2 describe-instances
aws s3 ls
```

## Конвертація слайдів

### Marp

**Встановлення**:
```bash
npm install -g @marp-team/marp-cli
```

**Використання**:
```bash
# PDF
marp slides.md --pdf

# PowerPoint
marp slides.md --pptx

# HTML
marp slides.md --html

# З кастомною темою
marp slides.md --theme custom-theme.css --pdf
```

**Опції**:
```bash
# Відкрити в браузері для попереднього перегляду
marp slides.md --preview

# Watch mode (автоматичне оновлення)
marp slides.md --watch
```

### reveal.js

**Встановлення**:
```bash
npm install -g reveal-md
```

**Використання**:
```bash
# Запустити локальний сервер
reveal-md slides.md

# Експорт в PDF
reveal-md slides.md --print slides.pdf

# З кастомною темою
reveal-md slides.md --theme custom
```

### Slidev

**Встановлення**:
```bash
npm install -g @slidev/cli
```

**Використання**:
```bash
# Запустити
slidev slides.md

# Експорт
slidev export slides.md
```

## Часті питання (FAQ)

**Q: Який формат презентації найкраще використовувати?**  
A: Рекомендуємо HTML-презентацію (presentation.html) - вона готова до використання, не потребує додаткових інструментів і працює в будь-якому браузері. Просто відкрийте файл!

**Q: Як керувати HTML-презентацією?**  
A: 
- Стрілки ← → на клавіатурі
- Пробіл для переходу на наступний слайд
- Кнопки "Назад"/"Вперед" на екрані
- Свайп на мобільних пристроях
- Home/End для першого/останнього слайда

**Q: Чи можу я редагувати матеріали?**  
A: Так! Всі файли в Markdown форматі - легко редагувати будь-яким текстовим редактором. HTML-презентацію також можна редагувати, але потрібно знати HTML/CSS.

**Q: Як додати власні слайди?**  
A: Відредагуйте slides.md. Кожен розділ відокремлений `---`.

**Q: Чи можна використовувати інший cloud провайдер для прикладів?**  
A: Так, концепції універсальні. Замініть AWS приклади на Azure/GCP за потреби.

**Q: Скільки коштує AWS для практики?**  
A: З Free Tier - безкоштовно! Але налаштуйте billing alerts на всяк випадок.

**Q: Де знайти додаткові матеріали?**  
A: Дивіться references.md - там сотні посилань на курси, книги, документацію.

**Q: Як конвертувати в PowerPoint без Marp?**  
A: Використайте pandoc:
```bash
pandoc slides.md -o slides.pptx
```

**Q: Чи є українські ресурси по cloud?**  
A: Так, дивіться секцію "Додаткові українські ресурси" в references.md.
