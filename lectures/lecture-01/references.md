## Книги

### Базові концепції Cloud Computing

**"Cloud Computing: Concepts, Technology & Architecture"**  
📚 Автори: Thomas Erl, Ricardo Puttini, Zaigham Mahmood  
Видавництво: Prentice Hall, 2013  
Комплексний огляд концепцій, технологій та архітектурних патернів хмарних обчислень

**"Cloud Native Patterns: Designing change-tolerant software"**  
📚 Автор: Cornelia Davis  
Видавництво: Manning Publications, 2019  
Патерни проектування cloud-native додатків

**"Architecting the Cloud: Design Decisions for Cloud Computing Service Models"**  
📚 Автор: Michael J. Kavis  
Видавництво: Wiley, 2014  
Рішення при проектуванні хмарних сервісів

### AWS-специфічні

**"AWS Certified Solutions Architect Study Guide"**  
📚 Автори: Ben Piper, David Clinton  
Видавництво: Sybex, останнє видання  
Детальний гайд по AWS архітектурі

**"Amazon Web Services in Action"**  
📚 Автори: Andreas Wittig, Michael Wittig  
Видавництво: Manning Publications, 2023 (3rd edition)  
Практичний гайд по AWS

### Infrastructure as Code

**"Terraform: Up & Running"**  
📚 Автор: Yevgeniy Brikman  
Видавництво: O'Reilly Media, 2022 (3rd edition)  
Комплексний гайд по Terraform

**"Infrastructure as Code: Dynamic Systems for the Cloud Age"**  
📚 Автор: Kief Morris  
Видавництво: O'Reilly Media, 2020 (2nd edition)  
Principles and patterns для IaC
