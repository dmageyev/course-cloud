# Лекція 1: Вступ до хмарних обчислень

## Огляд

Ця лекція знайомить студентів з основами хмарних обчислень, їх еволюцією та ключовими характеристиками.

## Теми

1. Історична еволюція обчислень (від мейнфреймів до хмар)
2. Визначення хмарних обчислень за NIST
3. П'ять ключових характеристик хмарних систем
4. Переваги та виклики хмарних технологій
5. Огляд AWS як референсної платформи

## Тривалість

90 хвилин

## Матеріали

- `notes.md` - Детальний конспект лекції
- `slides.md` - Презентаційні слайди
- `references.md` - Список літератури та ресурсів

## Очікувані результати

Після вивчення цієї лекції студенти зможуть:
- Пояснити еволюцію обчислювальних технологій
- Визначити ключові характеристики хмарних систем
- Розрізняти хмарні та традиційні підходи
- Описати основні переваги та виклики хмарних технологій
