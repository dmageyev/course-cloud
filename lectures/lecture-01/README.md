# Лекція 1: Хмарні обчислення як архітектурна парадигма

## Огляд

Ця лекція знайомить студентів з хмарними обчисленнями як фундаментальною архітектурною парадигмою сучасних інформаційних систем.

## Теорія

- Еволюція ІТ-інфраструктури
- Визначення Cloud (NIST)
- IaaS / PaaS / SaaS
- Public / Private / Hybrid / Multi-cloud
- Cloud ≠ AWS
- API-first, automation-first підхід

## AWS-приклади

- AWS як реалізація архітектурних принципів
- Free Tier, регіони

## Тривалість

2 години (90 хвилин)

## Матеріали

- `notes.md` - Детальний конспект лекції
- `slides.md` - Презентаційні слайди
- `references.md` - Список літератури та ресурсів

## Очікувані результати

Після вивчення цієї лекції студенти зможуть:
- Пояснити еволюцію ІТ-інфраструктури до хмарних обчислень
- Визначити основні моделі обслуговування та розгортання
- Розрізняти хмарні платформи та розуміти принципи vendor-agnostic підходу
- Застосовувати API-first та automation-first мислення
