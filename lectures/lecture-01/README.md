# Лекція 1: Хмарні обчислення як архітектурна парадигма

## Огляд

Ця лекція знайомить студентів з хмарними обчисленнями як фундаментальною архітектурною парадигмою сучасних інформаційних систем.

**Рівень**: Бакалаври 3 курс, ІТ напрямок  
**Тривалість**: 2 години (90 хвилин)

## Зміст лекції

### Теоретична частина

1. **Еволюція ІТ-інфраструктури**
   - Mainframe Era → Client-Server → Віртуалізація → Cloud
   - Виклики традиційного підходу

2. **Визначення Cloud Computing (NIST)**
   - 5 основних характеристик
   - On-demand self-service, Broad network access, Resource pooling, Rapid elasticity, Measured service

3. **Моделі обслуговування**
   - IaaS (Infrastructure as a Service)
   - PaaS (Platform as a Service)
   - SaaS (Software as a Service)

4. **Моделі розгортання**
   - Public Cloud
   - Private Cloud
   - Hybrid Cloud
   - Multi-Cloud

5. **Cloud ≠ AWS**
   - Vendor-Agnostic підхід
   - Порівняння провайдерів (AWS, Azure, GCP)

6. **Сучасні принципи**
   - API-First підхід
   - Automation-First мислення
   - Infrastructure as Code

### Практична частина

7. **AWS як приклад реалізації**
   - Глобальна інфраструктура (Regions, Availability Zones)
   - AWS Free Tier
   - Основні сервіси
   - Well-Architected Framework

## Домашнє завдання

1. **Створити AWS Free Tier акаунт**
   - Зареєструватись на aws.amazon.com
   - Налаштувати MFA
   - Встановити billing alerts

2. **Запустити першу EC2 instance**
   - Використати Free Tier eligible instance (t2.micro)
   - Підключитись через SSH
   - Зупинити після експериментів

3. **Ознайомитись з AWS CLI**
   - Встановити AWS CLI
   - Налаштувати credentials
   - Виконати базові команди (list S3 buckets, describe EC2 instances)

4. **Опціонально**: Почати вивчення Terraform basics
