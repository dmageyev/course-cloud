# Лекція 6: Зберігання даних у хмарі

## Огляд

Ця лекція присвячена різним типам систем зберігання даних у хмарних середовищах.

## Теми

1. Типологія систем зберігання: об'єктне, блокове, файлове
2. Розподілені файлові системи
3. NoSQL та NewSQL бази даних
4. Моделі консистентності даних
5. Стратегії резервного копіювання
6. Приклади AWS: S3, EBS, EFS, RDS, DynamoDB, Aurora

## Тривалість

90 хвилин

## Матеріали

- `notes.md` - Детальний конспект лекції
- `slides.md` - Презентаційні слайди
- `references.md` - Список літератури та ресурсів

## Очікувані результати

Після вивчення цієї лекції студенти зможуть:
- Розрізняти типи систем зберігання даних
- Вибирати відповідну систему для конкретного застосунку
- Розуміти компроміси між консистентністю та доступністю
- Проектувати стратегії резервного копіювання
