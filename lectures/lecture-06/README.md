# Лекція 6: Зберігання даних та життєвий цикл

## Огляд

Ця лекція присвячена різним типам систем зберігання даних у хмарних середовищах та управлінню життєвим циклом даних.

## Теорія

- Object / Block / File storage
- Data lifecycle
- Backup vs Archive
- CAP theorem
- GDPR, data residency

## AWS-приклади

- S3 (Lifecycle, versioning)
- EBS
- EFS

## Тривалість

2 години (90 хвилин)

## Матеріали

- `notes.md` - Детальний конспект лекції
- `slides.md` - Презентаційні слайди
- `references.md` - Список літератури та ресурсів

## Очікувані результати

Після вивчення цієї лекції студенти зможуть:
- Розрізняти типи систем зберігання (об'єктне, блокове, файлове)
- Управляти життєвим циклом даних
- Розрізняти backup та archive стратегії
- Застосовувати CAP theorem до систем зберігання
- Розуміти вимоги GDPR та data residency
