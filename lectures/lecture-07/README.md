# Лекція 7: Мережеві аспекти хмарних систем

## Огляд

Ця лекція розглядає мережеву архітектуру хмарних платформ та принципи розподілу трафіку.

## Теми

1. Віртуальні приватні хмари (VPC)
2. Програмно-визначені мережі (SDN)
3. Балансування навантаження: алгоритми та стратегії
4. Content Delivery Networks (CDN)
5. Мережева безпека та сегментація
6. Приклади AWS: VPC, ELB, Route 53, CloudFront

## Тривалість

90 хвилин

## Матеріали

- `notes.md` - Детальний конспект лекції
- `slides.md` - Презентаційні слайди

## Очікувані результати

Після вивчення цієї лекції студенти зможуть:
- Проектувати віртуальні мережі у хмарі
- Розуміти принципи роботи балансувальників навантаження
- Пояснювати механізми роботи CDN
- Налаштовувати мережеву безпеку
