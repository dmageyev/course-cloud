# Лекція 7: Хмарні бази даних

## Огляд

Ця лекція розглядає бази даних у хмарному середовищі, їх типи та паттерни використання.

## Теорія

- RDBMS vs NoSQL
- ACID vs BASE
- DB як bottleneck
- Scaling databases
- Anti-patterns

## AWS-приклади

- RDS
- DynamoDB
- Aurora
- Multi-AZ

## Тривалість

2 години (90 хвилин)

## Матеріали

- `notes.md` - Детальний конспект лекції
- `slides.md` - Презентаційні слайди
- `references.md` - Список літератури та ресурсів

## Очікувані результати

Після вивчення цієї лекції студенти зможуть:
- Порівнювати RDBMS та NoSQL підходи
- Розуміти різницю між ACID та BASE
- Ідентифікувати БД як bottleneck
- Застосовувати стратегії масштабування баз даних
- Уникати типових anti-patterns
