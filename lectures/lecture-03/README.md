# Лекція 3: Безпека хмарних ІС: DevSecOps mindset

## Огляд

Ця лекція фокусується на безпеці хмарних інформаційних систем з позиції DevSecOps підходу.

## Теорія

- Threat model у хмарі
- Misconfiguration як головний ризик
- IAM як архітектурний компонент
- Least privilege
- Zero Trust
- Dev / Staging / Prod

## AWS-приклади

- IAM users, roles, policies
- Security Groups vs NACL
- MFA

## Тривалість

2 години (90 хвилин)

## Матеріали

- `notes.md` - Детальний конспект лекції
- `slides.md` - Презентаційні слайди
- `references.md` - Список літератури та ресурсів

## Очікувані результати

Після вивчення цієї лекції студенти зможуть:
- Моделювати загрози в хмарному середовищі
- Розуміти та попереджати типові помилки конфігурації
- Застосовувати принципи least privilege та Zero Trust
- Проектувати IAM політики
- Розділяти середовища Dev/Staging/Prod
