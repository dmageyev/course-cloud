# Лекція 4: Мережева архітектура хмар

## Огляд

Ця лекція розглядає принципи проектування мережевої архітектури хмарних систем.

## Теорія

- VPC як логічна ізоляція
- CIDR, IP-addressing
- Public vs Private subnet
- Routing, NAT
- Ingress / Egress
- Bastion host
- 2-tier / 3-tier patterns

## AWS-приклади

- VPC, Subnets
- Route Tables
- IGW, NAT Gateway

## Тривалість

2 години (90 хвилин)

## Матеріали

- `notes.md` - Детальний конспект лекції
- `slides.md` - Презентаційні слайди
- `references.md` - Список літератури та ресурсів

## Очікувані результати

Після вивчення цієї лекції студенти зможуть:
- Проектувати VPC з урахуванням ізоляції
- Розраховувати CIDR блоки та IP-адресацію
- Розрізняти публічні та приватні підмережі
- Налаштовувати маршрутизацію та NAT
- Застосовувати багаторівневі архітектурні патерни
