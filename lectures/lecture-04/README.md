# Лекція 4: Архітектура хмарних систем

## Огляд

Ця лекція фокусується на архітектурних принципах проектування хмарних систем та розподілених застосунків.

## Теми

1. Принципи розподілених систем
2. CAP-теорема та її наслідки
3. Мікросервісна архітектура
4. Serverless computing
5. Архітектурні патерни хмарних систем
6. Приклади AWS: архітектурні рішення

## Тривалість

90 хвилин

## Матеріали

- `notes.md` - Детальний конспект лекції
- `slides.md` - Презентаційні слайди
- `references.md` - Список літератури та ресурсів

## Очікувані результати

Після вивчення цієї лекції студенти зможуть:
- Пояснювати принципи розподілених систем
- Застосовувати CAP-теорему при проектуванні
- Розрізняти монолітну та мікросервісну архітектури
- Проектувати хмарні застосунки з використанням патернів
