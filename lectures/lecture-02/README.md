# Лекція 2: Глобальна архітектура хмар та відповідальність

## Огляд

Ця лекція розглядає глобальну архітектуру хмарних платформ, концепції відповідальності та проектування відмовостійких систем.

## Теорія

- Regions, AZ, Edge
- Latency, data residency
- SLA, SLO, availability
- Shared Responsibility Model
- RTO / RPO
- Design for failure

## AWS-приклади

- Multi-AZ
- Реальні outage кейси

## Тривалість

2 години (90 хвилин)

## Матеріали

- `notes.md` - Детальний конспект лекції
- `slides.md` - Презентаційні слайди
- `references.md` - Список літератури та ресурсів

## Очікувані результати

Після вивчення цієї лекції студенти зможуть:
- Розуміти глобальну архітектуру хмарних платформ
- Пояснювати модель спільної відповідальності
- Аналізувати SLA, SLO та метрики доступності
- Проектувати системи з урахуванням можливих відмов
- Розраховувати RTO/RPO для різних сценаріїв
