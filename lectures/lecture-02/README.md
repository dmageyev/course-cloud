# Лекція 2: Моделі обслуговування

## Огляд

Ця лекція детально розглядає три основні моделі обслуговування хмарних систем: IaaS, PaaS та SaaS.

## Теми

1. Теоретичні основи сервісних моделей
2. Infrastructure as a Service (IaaS)
3. Platform as a Service (PaaS)
4. Software as a Service (SaaS)
5. Порівняльний аналіз моделей
6. Приклади AWS: EC2, Elastic Beanstalk, WorkSpaces

## Тривалість

90 хвилин

## Очікувані результати

Після вивчення цієї лекції студенти зможуть:
- Розрізняти моделі обслуговування IaaS, PaaS, SaaS
- Аналізувати переваги та недоліки кожної моделі
- Вибирати відповідну модель для конкретних сценаріїв
- Пояснити архітектурні відмінності між моделями
