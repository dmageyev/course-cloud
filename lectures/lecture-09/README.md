# Лекція 9: Cloud-native та контейнеризація

## Огляд

Ця лекція розглядає cloud-native підхід, принципи контейнеризації та сучасні архітектурні паттерни.

## Теорія

- Cloud-native principles
- Microservices
- Containers
- Docker (concept)
- Kubernetes (idea, no practice)
- Event-driven systems

## AWS-приклади

- ECS / EKS (overview)
- Lambda

## Тривалість

2 години (90 хвилин)

## Матеріали

- `notes.md` - Детальний конспект лекції
- `slides.md` - Презентаційні слайди
- `references.md` - Список літератури та ресурсів

## Очікувані результати

Після вивчення цієї лекції студенти зможуть:
- Розуміти cloud-native принципи
- Пояснювати переваги мікросервісної архітектури
- Розрізняти контейнери та віртуальні машини
- Розуміти концепції Docker та Kubernetes
- Застосовувати event-driven підходи
