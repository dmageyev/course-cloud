# Лекція 9: Масштабованість та відмовостійкість

## Огляд

Ця лекція розглядає принципи проектування масштабованих та відмовостійких хмарних систем.

## Теми

1. Теорія масштабованості: горизонтальне vs вертикальне
2. Патерни високої доступності
3. Disaster Recovery: стратегії та метрики
4. Механізми відмовостійкості
5. Chaos Engineering
6. Приклади AWS: Auto Scaling, Multi-AZ, Multi-Region

## Тривалість

90 хвилин

## Матеріали

- `notes.md` - Детальний конспект лекції
- `slides.md` - Презентаційні слайди
- `references.md` - Список літератури та ресурсів

## Очікувані результати

Після вивчення цієї лекції студенти зможуть:
- Проектувати масштабовані системи
- Розраховувати метрики доступності
- Розробляти стратегії відновлення після збоїв
- Застосовувати патерни високої доступності
