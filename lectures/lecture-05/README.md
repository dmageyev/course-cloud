# Лекція 5: Віртуалізація та контейнеризація

## Огляд

Ця лекція розглядає технології віртуалізації та контейнеризації як основу хмарних обчислень.

## Теми

1. Теоретичні основи віртуалізації
2. Гіпервізори: типи та архітектура
3. Контейнерні технології
4. Порівняння віртуальних машин та контейнерів
5. Kubernetes: архітектура та концепції
6. Приклади AWS: EC2, ECS, EKS, Fargate

## Тривалість

90 хвилин

## Матеріали

- `notes.md` - Детальний конспект лекції
- `slides.md` - Презентаційні слайди
- `references.md` - Список літератури та ресурсів

## Очікувані результати

Після вивчення цієї лекції студенти зможуть:
- Пояснювати принципи роботи віртуалізації
- Розрізняти типи гіпервізорів
- Порівнювати контейнери та віртуальні машини
- Розуміти основи оркестрації контейнерів
