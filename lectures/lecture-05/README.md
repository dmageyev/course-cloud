# Лекція 5: Обчислювальні ресурси та Linux у хмарі

## Огляд

Ця лекція розглядає обчислювальні ресурси в хмарі з фокусом на Linux-based системи.

## Теорія

- Гіпервізори
- VM vs Containers vs Serverless
- Linux-first mindset
- systemd, services, ports
- Immutable vs mutable infra
- Stateless systems

## AWS-приклади

- EC2
- Auto Scaling
- AMI

## Тривалість

2 години (90 хвилин)

## Матеріали

- `notes.md` - Детальний конспект лекції
- `slides.md` - Презентаційні слайди
- `references.md` - Список літератури та ресурсів

## Очікувані результати

Після вивчення цієї лекції студенти зможуть:
- Розуміти принципи роботи гіпервізорів
- Порівнювати VM, контейнери та serverless
- Працювати з Linux у хмарному середовищі
- Розрізняти immutable та mutable інфраструктуру
- Проектувати stateless системи
