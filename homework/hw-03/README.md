# Домашнє завдання 3: DevSecOps mindset

## Мета

Проаналізувати реальний cloud security incident та зробити висновки щодо типових помилок та їх попередження.

## Завдання

1. **Знайти cloud security incident**
   - Вибрати публічно описаний security incident (data breach, misconfiguration, тощо)
   - Джерела: блоги безпеки, CVE, новини про витоки даних
   - Інцидент має бути пов'язаний з хмарною інфраструктурою

2. **Проаналізувати incident**
   - Що сталося? (timeline подій)
   - Яка була причина? (root cause)
   - Які сервіси/компоненти були задіяні?
   - Який був масштаб наслідків?
   - Як інцидент було виявлено?

3. **Ідентифікувати помилки**
   - Які помилки в конфігурації/архітектурі призвели до інциденту?
   - Які DevSecOps практики не було дотримано?
   - Які security controls були відсутні?

4. **Запропонувати рішення**
   - Як можна було попередити цей інцидент?
   - Які security measures варто впровадити?
   - Які AWS сервіси/features могли б допомогти?
   - Чек-лист для попередження подібних інцидентів

## Формат здачі

Документ (Markdown або PDF) який містить:
1. Опис інциденту (з посиланням на джерело)
2. Timeline та root cause analysis
3. Аналіз помилок з DevSecOps perspective
4. Запропоновані заходи попередження
5. Висновки та lessons learned

## Критерії оцінювання

- Вибір релевантного інциденту - 15%
- Повнота аналізу - 25%
- Глибина розуміння DevSecOps - 25%
- Практичність запропонованих рішень - 25%
- Якість висновків - 10%
