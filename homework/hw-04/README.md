# Домашнє завдання 4: FinOps

## Мета

Оцінити вартість хмарної архітектури та запропонувати оптимізацію з позиції FinOps.

## Завдання

1. **Вибрати архітектуру для аналізу**
   - Використати свою архітектуру з ДЗ2
   - АБО вибрати запропоновану викладачем
   - АБО проаналізувати архітектуру з AWS Architecture Center

2. **Оцінити вартість**
   Для кожного компоненту визначити:
   - AWS сервіс та його конфігурація
   - Очікуване використання (compute hours, storage GB, requests)
   - Місячна вартість
   - Використати AWS Pricing Calculator

3. **Проаналізувати структуру витрат**
   - Які компоненти найдорожчі?
   - Які витрати змінні, які фіксовані?
   - Як витрати залежать від навантаження?
   - Де є потенціал для оптимізації?

4. **Запропонувати оптимізацію**
   Розглянути можливості:
   - Reserved Instances / Savings Plans
   - Spot Instances для non-critical workloads
   - S3 lifecycle policies
   - Auto Scaling налаштування
   - Right-sizing instances
   - Архітектурні зміни для зменшення витрат

5. **Розрахувати економію**
   - Порівняти вартість до і після оптимізації
   - Визначити ROI оптимізації
   - Виявити trade-offs (що втрачаємо, що виграємо)

## Формат здачі

Документ (Markdown, Excel, або PDF) який містить:

1. **Baseline Cost Analysis**
   - Таблиця з компонентами та їх вартістю
   - Загальна місячна вартість
   - Breakdown по категоріях

2. **Cost Optimization Plan**
   - Список запропонованих оптимізацій
   - Очікувана економія для кожної
   - Пріоритизація пропозицій

3. **Optimized Cost Projection**
   - Таблиця з оптимізованою вартістю
   - Порівняння з baseline
   - % економії

4. **Implementation Plan**
   - Як впроваджувати оптимізації
   - Які ризики та trade-offs
   - Monitoring та контроль

## Критерії оцінювання

- Точність розрахунків вартості - 25%
- Глибина аналізу - 20%
- Креативність оптимізацій - 25%
- Реалістичність пропозицій - 20%
- Якість презентації даних - 10%
