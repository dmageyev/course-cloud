# Домашнє завдання 1: Git

## Мета

Продемонструвати навички роботи з Git та створення технічної документації для cloud-проєктів.

## Теоретичні основи

- Git workflow
- Branching strategies
- Pull Requests
- Technical documentation
- Architecture diagrams

## Завдання

1. **Fork репозиторію курсу**
   - Створити fork основного репозиторію
   - Клонувати fork локально

2. **Створити README з архітектурною діаграмою**
   - Описати запропоновану хмарну архітектуру
   - Створити architecture diagram (draw.io, Lucidchart, або PlantUML)
   - Додати пояснення вибору сервісів
   - Описати компоненти та їх взаємодію

3. **Створити Pull Request**
   - Зробити commit з описовими повідомленнями
   - Створити PR з детальним описом змін
   - Відповісти на коментарі (якщо будуть)

## Структура README

```markdown
# Cloud Architecture Proposal

## Overview
[Короткий опис системи]

## Architecture Diagram
[Діаграма]

## Components
- **Component 1**: опис
- **Component 2**: опис

## Technology Choices
[Обґрунтування вибору сервісів]

## Security Considerations
[Аспекти безпеки]

## Scalability
[Як система масштабується]
```

## Критерії оцінювання

- Правильне використання Git (fork, commits, PR) - 25%
- Якість архітектурної діаграми - 25%
- Повнота технічної документації - 25%
- Обґрунтованість технічних рішень - 25%
