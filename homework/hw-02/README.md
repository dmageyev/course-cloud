# Домашнє завдання 2: Cloud Architecture

## Мета

Спроєктувати хмарну архітектуру для конкретного кейсу та обґрунтувати вибір сервісів.

## Кейс

Вам потрібно спроєктувати хмарну інфраструктуру для **[кейс буде надано викладачем]**

Приклади кейсів:
- E-commerce платформа з очікуваним трафіком 10,000 користувачів/день
- Система аналітики даних для обробки логів
- SaaS додаток для команд розробників
- Mobile backend для додатку з геолокацією

## Завдання

1. **Проаналізувати вимоги**
   - Функціональні вимоги
   - Non-functional вимоги (продуктивність, доступність, безпека)
   - Очікуване навантаження
   - Бюджетні обмеження

2. **Спроєктувати архітектуру**
   - Вибрати AWS сервіси
   - Створити архітектурну діаграму
   - Описати потік даних
   - Визначити zones доступності

3. **Обґрунтувати рішення**
   - Чому обрано саме ці сервіси
   - Як забезпечується high availability
   - Як система масштабується
   - Які security заходи впроваджено

4. **Оцінити вартість**
   - Приблизна місячна вартість
   - Можливості оптимізації

## Формат здачі

Документ (Markdown або PDF) який містить:
- Опис кейсу та вимог
- Архітектурна діаграма
- Список сервісів з обґрунтуванням
- Security considerations
- Scalability strategy
- Попередня оцінка вартості

## Критерії оцінювання

- Повнота аналізу вимог - 20%
- Якість архітектурного рішення - 30%
- Обґрунтованість вибору сервісів - 25%
- Врахування безпеки та масштабованості - 15%
- Оцінка вартості - 10%
