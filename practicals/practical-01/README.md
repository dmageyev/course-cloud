# Практична робота 1: Розгортання базової хмарної інфраструктури

## Мета

Набути практичних навичок розгортання базової хмарної інфраструктури з використанням основних компонентів.

## Тривалість

2 академічні години

## Теоретичні основи

- Віртуальні приватні хмари (VPC)
- Обчислювальні ресурси (EC2)
- Групи безпеки та мережева ізоляція

## Завдання

1. Створити віртуальну приватну хмару (VPC)
2. Налаштувати підмережі (публічну та приватну)
3. Створити обчислювальні ресурси (EC2 інстанси)
4. Сконфігурувати групи безпеки
5. Перевірити підключення та функціональність

## Матеріали

- `instructions.md` - Детальні інструкції
- `tasks.md` - Завдання для виконання
- `questions.md` - Контрольні питання

## Очікувані результати

Студенти зможуть:
- Розгортати базову мережеву інфраструктуру
- Створювати та налаштовувати обчислювальні ресурси
- Конфігурувати правила безпеки
- Тестувати підключення до ресурсів

## Критерії оцінювання

- Коректність налаштування VPC та підмереж (25%)
- Правильна конфігурація EC2 інстансів (25%)
- Адекватні правила безпеки (25%)
- Успішне тестування та документація (25%)
