# Практична робота 1: Git + Cloud workflow

## Мета

Набути практичних навичок роботи з системою контролю версій Git та організації cloud-проєктів.

## Тривалість

2 академічні години

## Зміст

**Робота з Git:**
- GitHub / GitLab
- Repo structure для cloud-проєкту
- README як технічна документація
- Cloud architecture diagram (draw.io)

## Завдання

1. Створити або форкнути репозиторій для cloud-проєкту
2. Налаштувати правильну структуру репозиторію
3. Написати технічну документацію у README.md
4. Створити архітектурну діаграму (draw.io, Lucidchart або аналоги)
5. Зробити commits з правильними повідомленнями
6. Створити Pull Request

## Матеріали

- `instructions.md` - Детальні інструкції
- `tasks.md` - Завдання для виконання
- `examples/` - Приклади структури та документації

## 🎯 Очікуваний результат

Студент вміє:
- Вести cloud-проєкт у Git
- Документувати технічні рішення
- Створювати архітектурні діаграми
- Працювати з Pull Requests

## Критерії оцінювання

- Правильна структура репозиторію (25%)
- Якість технічної документації (25%)
- Архітектурна діаграма (25%)
- Якість commits та PR (25%)
