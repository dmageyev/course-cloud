# Практична робота 2: Проектування масштабованого застосунку

## Мета

Набути практичних навичок проектування та реалізації масштабованої архітектури застосунку.

## Тривалість

2 академічні години

## Теоретичні основи

- Балансування навантаження
- Автоматичне масштабування
- Моніторинг метрик

## Завдання

1. Розгорнути застосунок на кількох інстансах
2. Налаштувати балансувальник навантаження (Load Balancer)
3. Сконфігурувати Auto Scaling Group
4. Налаштувати моніторинг метрик
5. Провести тестування під навантаженням

## Матеріали

- `instructions.md` - Детальні інструкції
- `tasks.md` - Завдання для виконання
- `questions.md` - Контрольні питання

## Очікувані результати

Студенти зможуть:
- Розгортати розподілені застосунки
- Налаштовувати балансування навантаження
- Конфігурувати автоматичне масштабування
- Аналізувати метрики продуктивності

## Критерії оцінювання

- Коректність налаштування Load Balancer (25%)
- Правильна конфігурація Auto Scaling (25%)
- Адекватне налаштування моніторингу (25%)
- Результати тестування та аналіз (25%)
