# Практична робота 2: DevSecOps: мислення і пайплайн

## Мета

Сформувати розуміння DevSecOps lifecycle та принципів побудови CI/CD pipelines.

## Тривалість

2 академічні години

## Зміст

**DevSecOps концепції:**
- CI/CD pipeline (conceptual)
- Secrets management
- Env separation
- Security scanning (idea)

## Завдання

1. Проаналізувати структуру CI/CD pipeline
2. Визначити етапи DevSecOps lifecycle
3. Спроектувати схему розділення середовищ (Dev/Staging/Prod)
4. Описати підхід до управління секретами
5. Скласти чек-лист security checks для pipeline

## Матеріали

- `instructions.md` - Детальні інструкції
- `tasks.md` - Завдання для виконання
- `examples/` - Приклади pipelines та діаграм

## 🎯 Очікуваний результат

Студент розуміє:
- Структуру та етапи CI/CD pipeline
- Принципи DevSecOps
- Важливість розділення середовищ
- Необхідність захисту секретів

## Критерії оцінювання

- Розуміння CI/CD концепцій (25%)
- Правильне розділення середовищ (25%)
- Підхід до secrets management (25%)
- Security mindset (25%)
