# Хмарні технології інформаційних систем

## Опис курсу

Даний курс призначений для студентів вищих навчальних закладів та охоплює теоретичні основи побудови хмарних інформаційних систем. Курс фокусується на архітектурних принципах, моделях обслуговування та практичних аспектах проектування хмарних рішень. Amazon Web Services (AWS) використовується як референсна платформа для демонстрації практичної реалізації теоретичних концепцій.

## Структура курсу

Курс складається з наступних компонентів:

### Лекції (10 занять)

1. **Лекція 1: Вступ до хмарних обчислень**
   - Визначення та еволюція хмарних технологій
   - Основні характеристики хмарних систем
   - Приклади AWS: Огляд платформи

2. **Лекція 2: Моделі обслуговування**
   - IaaS, PaaS, SaaS: теоретичні основи
   - Порівняльний аналіз моделей
   - Приклади AWS: EC2, Elastic Beanstalk, SaaS-сервіси

3. **Лекція 3: Моделі розгортання**
   - Публічні, приватні, гібридні хмари
   - Критерії вибору моделі розгортання
   - Приклади AWS: VPC, Direct Connect

4. **Лекція 4: Архітектура хмарних систем**
   - Принципи проектування розподілених систем
   - Мікросервісна архітектура
   - Приклади AWS: Архітектурні патерни

5. **Лекція 5: Віртуалізація та контейнеризація**
   - Теорія віртуалізації ресурсів
   - Контейнерні технології
   - Приклади AWS: EC2, ECS, EKS

6. **Лекція 6: Зберігання даних у хмарі**
   - Типи сховищ: об'єктне, блокове, файлове
   - Системи управління базами даних
   - Приклади AWS: S3, EBS, RDS, DynamoDB

7. **Лекція 7: Мережеві аспекти хмарних систем**
   - Мережева архітектура хмарних платформ
   - Балансування навантаження та CDN
   - Приклади AWS: VPC, ELB, CloudFront

8. **Лекція 8: Безпека хмарних систем**
   - Моделі відповідальності за безпеку
   - Ідентифікація та керування доступом
   - Приклади AWS: IAM, KMS, Security Groups

9. **Лекція 9: Масштабованість та відмовостійкість**
   - Горизонтальне та вертикальне масштабування
   - Патерни забезпечення високої доступності
   - Приклади AWS: Auto Scaling, Multi-AZ, Multi-Region

10. **Лекція 10: Моніторинг та оптимізація**
    - Системи моніторингу хмарних ресурсів
    - Оптимізація витрат та продуктивності
    - Приклади AWS: CloudWatch, Cost Explorer

### Практичні роботи (2 заняття)

1. **Практична робота 1: Розгортання базової хмарної інфраструктури**
   - Налаштування обчислювальних ресурсів
   - Конфігурація мережі та безпеки

2. **Практична робота 2: Проектування масштабованого застосунку**
   - Реалізація балансування навантаження
   - Налаштування автоматичного масштабування

### Лабораторні роботи (4 заняття)

1. **Лабораторна робота 1: Дослідження моделей обслуговування**
   - Порівняльний аналіз IaaS, PaaS, SaaS
   - Практичне розгортання різних моделей

2. **Лабораторна робота 2: Архітектура та віртуалізація**
   - Проектування архітектури хмарного застосунку
   - Робота з віртуальними машинами та контейнерами

3. **Лабораторна робота 3: Сховища даних та бази даних**
   - Імплементація різних типів сховищ
   - Налаштування та оптимізація баз даних

4. **Лабораторна робота 4: Безпека та моніторинг**
   - Реалізація політик безпеки
   - Налаштування систем моніторингу

## Методологія викладання

Курс побудований на принципах академічної освіти з акцентом на:
- Теоретичних основах хмарних обчислень
- Архітектурних принципах та патернах проектування
- Критичному аналізі та порівнянні підходів
- Практичній демонстрації концепцій через AWS

## Цільова аудиторія

Курс призначений для студентів, які:
- Мають базові знання з інформаційних систем
- Розуміють основи мережевих технологій
- Знайомі з принципами програмування

## Очікувані результати навчання

Після завершення курсу студенти зможуть:
- Пояснювати архітектурні принципи хмарних систем
- Аналізувати та порівнювати різні моделі обслуговування
- Проектувати масштабовані хмарні рішення
- Розуміти аспекти безпеки та оптимізації
- Застосовувати теоретичні знання на практиці
