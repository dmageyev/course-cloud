# Лабораторна робота 3: Storage + Database

## Мета

Працювати з різними типами систем зберігання даних та базами даних в AWS.

## Тривалість

2 академічні години

## Теоретичні основи

- S3 (Simple Storage Service)
- RDS (Relational Database Service)
- Static website hosting
- Database backups

## Завдання

1. Створити S3 bucket
2. Налаштувати static website hosting на S3
3. Завантажити статичний контент (HTML, CSS, JS)
4. Створити RDS інстанс (MySQL або PostgreSQL)
5. Налаштувати Security Groups для БД
6. Підключитися до БД та створити тестову базу
7. Налаштувати automated backups

## Матеріали

- `guide.md` - Методичні вказівки
- `tasks.md` - Покрокові завдання
- `examples/` - Приклади статичних сайтів та SQL скриптів

## Очікувані результати

Студенти зможуть:
- Працювати з об'єктним сховищем S3
- Розгортати статичні веб-сайти
- Створювати та налаштовувати RDS
- Підключатися до баз даних
- Налаштовувати backup стратегії

## Критерії оцінювання

- Налаштування S3 та static hosting (25%)
- Робота з RDS (30%)
- Security конфігурація (20%)
- Backup налаштування (25%)
