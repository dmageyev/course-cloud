# Лабораторна робота 3: Сховища даних та бази даних

## Мета

Дослідити різні типи систем зберігання даних у хмарних середовищах та їх характеристики.

## Тривалість

2 академічні години

## Теоретичні основи

- Об'єктне сховище (Object Storage)
- Блокове сховище (Block Storage)
- Реляційні бази даних
- NoSQL бази даних

## Завдання дослідження

1. Налаштувати об'єктне сховище (S3)
2. Створити та протестувати реляційну БД (RDS)
3. Розгорнути NoSQL рішення (DynamoDB)
4. Порівняти характеристики:
   - Продуктивність (латентність, пропускна здатність)
   - Консистентність даних
   - Масштабованість
   - Варість використання
5. Проаналізувати сценарії застосування

## Матеріали

- `guide.md` - Методичні вказівки
- `tasks.md` - Завдання
- `report-template.md` - Шаблон звіту

## Очікувані результати

Студенти зможуть:
- Працювати з різними типами сховищ
- Налаштовувати бази даних у хмарі
- Порівнювати характеристики різних систем
- Вибирати оптимальне рішення для конкретних потреб

## Вимоги до звіту

- Опис налаштувань кожної системи
- Результати тестування продуктивності
- Порівняльна таблиця характеристик
- Рекомендації щодо вибору системи зберігання
