# Лабораторна робота 1: Дослідження моделей обслуговування

## Мета

Провести порівняльне дослідження моделей обслуговування хмарних систем (IaaS, PaaS, SaaS).

## Тривалість

2 академічні години

## Теоретичні основи

- Infrastructure as a Service (IaaS)
- Platform as a Service (PaaS)
- Software as a Service (SaaS)

## Завдання дослідження

1. Розгорнути тестовий застосунок на рівні IaaS
2. Розгорнути той самий застосунок на рівні PaaS
3. Порівняти з SaaS рішенням
4. Виміряти та порівняти метрики:
   - Час розгортання
   - Складність налаштування
   - Рівень контролю
   - Вартість використання
5. Проаналізувати переваги та недоліки кожної моделі

## Матеріали

- `guide.md` - Методичні вказівки
- `tasks.md` - Завдання
- `report-template.md` - Шаблон звіту

## Очікувані результати

Студенти зможуть:
- Практично використовувати різні моделі обслуговування
- Проводити порівняльний аналіз
- Вибирати оптимальну модель для конкретних сценаріїв

## Вимоги до звіту

- Опис методології дослідження
- Результати вимірювань
- Порівняльний аналіз
- Висновки та рекомендації
