# Лабораторна робота 1: IAM + Secure AWS account

## Мета

Налаштувати безпечний AWS аккаунт з використанням IAM та впровадити least privilege принципи.

## Тривалість

2 академічні години

## Теоретичні основи

- Identity and Access Management (IAM)
- Least privilege principle
- Multi-Factor Authentication (MFA)
- IAM Policies

## Завдання

1. Створити IAM користувача та групу
2. Налаштувати MFA для root та IAM користувача
3. Створити IAM policy з least privilege
4. Задокументувати налаштування в Git (commit policy)
5. Протестувати доступ та права

## Матеріали

- `guide.md` - Методичні вказівки
- `tasks.md` - Детальні завдання
- `policy-examples/` - Приклади IAM policies

## Очікувані результати

Студенти зможуть:
- Створювати та керувати IAM користувачами
- Налаштовувати MFA
- Проектувати безпечні IAM policies
- Документувати security налаштування в Git

## Критерії оцінювання

- Правильне налаштування IAM (30%)
- MFA для всіх облікових записів (20%)
- Least privilege policy (30%)
- Git документація (20%)
