# Лабораторна робота 2: Networking + EC2

## Мета

Створити мережеву інфраструктуру в AWS та розгорнути EC2 інстанси з Linux.

## Тривалість

2 академічні години

## Теоретичні основи

- Virtual Private Cloud (VPC)
- Subnets (Public/Private)
- EC2 (Elastic Compute Cloud)
- Security Groups
- SSH ключі та підключення

## Завдання

1. Створити VPC з відповідною CIDR блоком
2. Налаштувати public subnet
3. Створити та налаштувати Internet Gateway
4. Запустити EC2 інстанс з Linux (Amazon Linux 2 або Ubuntu)
5. Налаштувати Security Groups для SSH доступу
6. Підключитися до інстансу через SSH
7. Виконати базові Linux команди

## Матеріали

## Очікувані результати

Студенти зможуть:
- Проектувати та створювати VPC
- Налаштовувати підмережі та маршрутизацію
- Запускати та конфігурувати EC2 інстанси
- Працювати з Linux через SSH
- Налаштовувати мережеву безпеку

## Критерії оцінювання

- Правильна конфігурація VPC (25%)
- Налаштування EC2 (25%)
- Security Groups (25%)
- Успішне підключення та робота з Linux (25%)
