# Лабораторна робота 4: Highly Available Web Architecture

## Мета

Побудувати високодоступну веб-архітектуру з балансуванням навантаження та автоматичним масштабуванням.

## Тривалість

2 академічні години

## Теоретичні основи

- Application Load Balancer (ALB)
- Auto Scaling Groups (ASG)
- High Availability patterns
- CloudWatch monitoring

## Завдання

1. Підготувати 2 EC2 інстанси з веб-сервером
2. Створити та налаштувати Application Load Balancer
3. Налаштувати Target Group
4. Створити Launch Template
5. Налаштувати Auto Scaling Group
6. Налаштувати CloudWatch моніторинг
7. Протестувати масштабування під навантаженням

## Матеріали

- `guide.md` - Методичні вказівки
- `tasks.md` - Покрокові завдання
- `scripts/` - Скрипти для налаштування веб-серверів
- `load-testing/` - Інструкції для тестування навантаження

## Очікувані результати

Студенти зможуть:
- Створювати високодоступні архітектури
- Налаштовувати балансування навантаження
- Конфігурувати автоматичне масштабування
- Моніторити стан системи через CloudWatch
- Тестувати систему під навантаженням

## Критерії оцінювання

- Налаштування ALB (25%)
- Конфігурація ASG (25%)
- CloudWatch моніторинг (25%)
- Тестування та аналіз результатів (25%)
