# Лабораторна робота 4: Безпека та моніторинг

## Мета

Дослідити механізми забезпечення безпеки хмарних систем та налаштування моніторингу.

## Тривалість

2 академічні години

## Теоретичні основи

- Identity and Access Management (IAM)
- Мережева безпека
- Моніторинг та логування
- Аналіз метрик

## Завдання дослідження

1. Налаштувати політики IAM для різних ролей
2. Сконфігурувати групи безпеки та мережеві ACL
3. Налаштувати моніторинг за допомогою CloudWatch
4. Налаштувати збір та аналіз логів
5. Створити дашборди та налаштувати алерти
6. Проаналізувати метрики безпеки та продуктивності

## Матеріали

- `guide.md` - Методичні вказівки
- `tasks.md` - Завдання
- `report-template.md` - Шаблон звіту

## Очікувані результати

Студенти зможуть:
- Налаштовувати політики доступу
- Конфігурувати мережеву безпеку
- Налаштовувати системи моніторингу
- Аналізувати логи та метрики
- Реагувати на інциденти безпеки

## Вимоги до звіту

- Опис налаштованих політик безпеки
- Скріншоти конфігурацій
- Результати моніторингу
- Аналіз потенційних загроз
- Рекомендації щодо покращення безпеки
